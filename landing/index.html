  1. 01
    BRIEF & PLAN

    把想象，拆成计划。

    检查能力、媒体路线与引擎环境，由只读 Planner 定义任务与验收条件。

  2. 02
    BUILD & ASSETS

    让世界，逐渐成形。

    Implementer 编写工程、组织素材。图片、音乐、音效与 3D 可接入配置的生成路线。

  3. 03
    REVIEW & REPAIR

    独立审查，继续打磨。

    Reviewer 检查真实结果。审查、构建或试玩未通过，交回同一 Implementer 修复，最多三轮。

  4. 04
    BUILD & PLAYTEST

    真正运行，然后交付。

    宿主正式构建，并用隔离浏览器操作核心玩法、捕获截图与运行错误。未通过门禁的任务保留为 blocked。

BEFORE YOU JUMP IN

好奇，是个好开始。

关于这个仍在生长的工作台。

现在可以制作什么类型的游戏？+

当前支持 Web 与 Godot 4 / GDScript 游戏工程。Godot 自动交付使用 Compatibility renderer 的 Web 导出；原生 macOS、Windows、Linux 游戏可执行包尚未接通。具体效果取决于模型、需求、依赖和媒体能力。

这是在线生成服务吗？+

它是本地优先的 Electron 桌面工作台。工程、素材与制作状态在本地管理；使用 Codex 与外部媒体 Provider 时仍需要网络。本页试玩只是浏览器内的交互概念演示，不会调用模型。

有可以直接下载的安装包吗？+

目前请从源码运行。当前发行目标为 macOS，尚未发布已签名、公证的安装包；Windows 与 Linux 桌面工作流仍在路线图中。

我可以接入自己的模型工具和素材服务吗？+

项目支持配置图片、音频与 3D REST Provider，以及 Codex Skills、stdio / HTTP MCP Server 与分角色提示词。具体接口契约和限制请查看仓库中的架构与功能文档。

项目采用什么许可证？+

Open game.ai 由 suhongshuo 开发与维护，源码采用 MIT 许可证发布。你可以使用、修改和分发项目，具体条款请查看仓库中的 LICENSE；第三方依赖遵循各自许可证。
